# 🌴 Goa Travel Blog

A simple travel blog webpage about Goa built using pure HTML. The project provides information about Goa, popular tourist destinations, beaches, activities, food, and includes an embedded Google Maps location.

## 📖 About the Project

This project was created as an HTML practice project to learn and apply fundamental HTML concepts.

The webpage presents Goa as a travel destination and organizes information into different sections such as attractions, activities, food, and location.

## ✨ Features

- Goa travel information
- Popular beaches and tourist attractions
- Things to do in Goa
- Goan food and local specialties
- Images using HTML `<img>`
- Ordered and unordered lists
- Embedded Google Maps location
- Semantic HTML structure
- Responsive viewport configuration

## 🛠️ Technologies Used

- HTML

## 📚 HTML Concepts Practiced

- HTML document structure
- Headings (`h1`, `h2`)
- Paragraphs (`p`)
- Images (`img`)
- Links and external resources
- Ordered lists (`ol`)
- Unordered lists (`ul`)
- List items (`li`)
- Text formatting with `<b>`
- Horizontal rules (`hr`)
- Embedded content using `<iframe>`
- Semantic elements such as `<main>` and `<section>`
